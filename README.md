# Sandbox Detector

Простой Python-инструмент для обнаружения запуска на виртуальной машине или в среде анализа. Демонстрирует базовые техники анти-песочницы и знакомит с WinAPI.

## Возможности
- Проверка MAC-адреса по базе сигнатур популярных гипервизоров (VirtualBox, VMware, Xen).
- Сканирование запущенных процессов на наличие отладчиков, инструментов анализа и гостевых служб.
- Оценка объема оперативной памяти для выявления легковесных песочниц.
- Обнаружение отладчика через WinAPI (`IsDebuggerPresent`).

## Использование
```bash
1. Запуск на реальной машине (Windows 10 22H2, 16 GB RAM)

```text
[*] Sandbox Detector запущен.
[*] Система: Windows 10.0.19045
[*] Имя компьютера: DESKTOP-COMMANDER
[+] Признаков виртуальной среды не обнаружено. Похоже на реальную машину.
```

2. Запуск внутри VirtualBox (Windows 10, 4 GB RAM)

```text
[*] Sandbox Detector запущен.
[*] Система: Windows 10.0.19041
[*] Имя компьютера: VBOX-TEST
[!] Обнаружен MAC-адрес виртуальной машины.
[!] Найдены процессы, характерные для анализа или виртуализации.
[!] Слишком мало оперативной памяти — возможно, песочница.
[-] Найдено 3 признаков виртуальной среды. Запуск на ВМ или под анализом.
```

3. Запуск с отладчиком (x64dbg)

```text
[*] Sandbox Detector запущен.
[*] Система: Windows 11.0.22621
[*] Имя компьютера: REVERSER-PC
[!] Найдены процессы, характерные для анализа или виртуализации.
[!] Обнаружен отладчик.
[-] Найдено 2 признаков виртуальной среды. Запуск на ВМ или под анализом.
```

4. Запуск в "песочнице" (Sandboxie / легковесная среда, 1 GB RAM)

```text
[*] Sandbox Detector запущен.
[*] Система: Windows 10.0.19041
[*] Имя компьютера: SANDBOX
[!] Найдены процессы, характерные для анализа или виртуализации.
[!] Слишком мало оперативной памяти — возможно, песочница.
[-] Найдено 2 признаков виртуальной среды. Запуск на ВМ или под анализом.
```
